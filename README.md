# MindBudget 財務管家｜公開體驗版

👉 **打開就能試：https://ws19135.github.io/mindbudget-demo/**

想花錢之前，先問一聲。MindBudget 是一個手機記帳＋預算＋「先問管家」的財務小幫手。
這個體驗版給朋友試用：**不用登入、不連雲端，裡面全是虛構數字。**

## 怎麼試（大約 5 分鐘）

1. 用手機打開上面的網址（電腦也可以）。
2. 選一個角色開始，畫面最上方的綠色工具列隨時可以切換：
   - **使用者**：每天記帳的人。看首頁、記一筆、預算提醒、先問管家、資產投資。
   - **管理者**：幫全家設定帳本的人。帳戶、固定收支、預算規則、提醒門檻、匯入備份、登入畫面。
   - **新手**：剛註冊、空帳本。從取名開始，看系統一步步跳出的引導、第一次記帳、管家的第一次對話。
3. 按工具列的「**導覽**」，照著步驟點，每一步都有按鈕直接帶你過去。
